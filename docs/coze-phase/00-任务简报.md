## 一、项目事实（已在 main 分支核实，作为你的起点，不得凭记忆另作假设）

- 仓库：社区开源版 `coze-dev/coze-studio`（https://github.com/coze-dev/coze-studio），本地路径 `/Users/hangwang/code26`，主分支为 `main`。
- 后端：Golang，微服务 + DDD 四层（api / application / domain / infra），HTTP 框架 Hertz，工作流运行时 Eino；领域模块在 `backend/domain/`（agent、app、conversation、knowledge、memory、plugin、prompt、template、connector、search 等）。
- 前端：React 18 + TypeScript，Rush monorepo（`frontend/packages/*`），Zustand + Semi Design，接口由 Thrift IDL 生成；工作流画布引擎为 FlowGram。
- 启动：`make web`（Docker Compose），本地 `http://localhost:8888`。
- 产品定位：主要用户是**不会编程的业务开发者**，所有功能以"业务开发者能自助跑通"为验收取向。

**最高优先级的认知前提（违反即方向性错误）**：

1. 社区版工作流是**结构化 DSL（节点 + 连线 JSON）存 MySQL**：后端节点结构是 `backend/domain/workflow/entity/vo/canvas.go` 的 `Node{ID, Type, Meta, Data, Blocks, Edges}`，前端由 FlowGram 的 `WorkflowDocument` 承载。
2. 社区版**不存在** `src/graphs/**.py / state.py / pyproject.toml / uv.lock` 这类 Python 平台工程（那是云端商业版「扣子编程」的形态；Python 只出现在工作流"代码节点"的运行沙箱里）。
3. 因此"AI 修改节点"在本项目 = **AI 生成/修改节点 DSL（严格 JSON patch）→ 用 FlowGram 命令写回文档模型 → 走现有保存接口**，**不是改磁盘 .py 源码，不做文件监听**。

### Phase 2 · AI 改节点 P1（右键 → 弹窗 → 左侧助手 → 改单节点 data；P1 纯前端）

**目标交互链路（逐条实现，不得缺环）：**

1. 画布节点新增**右键及「···」菜单项「使用 AI 修改该节点」**。
2. 点击弹出输入弹窗：文本框接收自然语言修改意图；**右上角【确认】按钮 + 【取消】按钮；取消直接关闭、不产生任何后续动作**；弹窗用 `components/bot-semi` 的 Modal。

4. 确认瞬间自动把上下文填入助手输入框：**节点 ID、节点类型、输入输出 schema、节点现有配置（即该节点 DSL 的 data）、当前工作流标识（原始需求称"workflow 文件路径"，社区版无磁盘文件，对应 workflow/DSL 标识）+ 用户修改指令**；注意 **Task 节点与 LLM 节点要分别提取各自元数据**。
5. 用户可在面板内继续多轮对话；提交后模型返回**该节点的 data patch（严格 JSON）**。
6. patch 先过 `workflow/nodes/src/workflow-json-format.ts` 与该节点 `data-transformer.tsx / form-meta.tsx` 校验；**非法 JSON 或校验失败一律不写回并在面板提示**；合法后用 FlowGram 命令写回 `WorkflowDocument`（自动进 `workflow/history` 撤销栈，可 Ctrl+Z）→ 画布即时重渲染 → 走现有 autosave/SaveWorkflow 持久化 MySQL。
7. 模型调用 P1 走快路：前端经 `arch/bot-api` + `arch/bot-http` 复用现成对话/SSE，用 JSON mode/function calling 强约束输出；P1 不改 Go（正规的后端 AI service + thrift idl + handler 留待后续）。
8. **边界约束**：P1 只允许改这一个节点内部 data（如大模型节点的 prompt、模型、输入输出描述），**不允许增删节点、不允许改连线**；**开始/结束等系统节点右键菜单项置灰不可点**（判定看 `nodes-v2/constants.ts`）；关闭面板回到正常画布；输出完整可运行变更，**不要伪代码**。
9. 验收：对一个大模型节点右键输入修改意图 → 确认后左侧面板自动带出完整上下文 → 返回后节点配置即时更新、可撤销、刷新页面后仍在（已持久化）；系统节点菜单置灰；取消无副作用；非法返回不写回。
